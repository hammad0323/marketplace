# My Website (React + React Router)

A modern multi-page website with **Home**, **About** and **Contact** pages, built with React, React Router and Vite.

```bash
npm install
npm run dev
```

- ✏️ Edit your content in `src/data/siteData.js`
- 🎨 Change colors in `src/index.css` (`--primary`, `--secondary`)
- 📘 **What to learn from this project:** [LEARNING.md](./LEARNING.md)
