# Zainco Packaging Industries — Website

Portfolio + e-commerce website for **Zainco Packaging Industries**, Karachi.
A static site (HTML, CSS, JavaScript). It needs no database, build step or server code,
so it runs on any web host or cPanel `public_html`, and you can also open it straight from a folder.

## Pages

| Page | File | What's on it |
|------|------|--------------|
| Home | `index.html` | 14 sections: parallax hero with floating products, marquee, stats counters, about, 9 product categories, parallax band, shop tabs, industries, 5-step process, why-us with progress bars, technical specs, testimonials slider, FAQ, CTA |
| About | `about.html` | Story, mission/vision/values, stats, timeline, facility, team, FAQ |
| Shop | `products.html` | 35 products, category filter, live search, sort |
| Product | `product.html?id=…` | Gallery with zoom, size/printing/quantity options, live total, specs tabs, related products |
| Cart & Checkout | `cart.html` | Editable cart (respects MOQ), checkout form, order sent via WhatsApp or email |
| Portfolio | `portfolio.html` | Filterable project gallery with lightbox |
| Contact | `contact.html` | Contact cards, quote form (sends via WhatsApp/email), Google Map |

## How orders work

There is no payment gateway. When a customer places an order or a quote request, the site
builds the full order and opens **WhatsApp to 0309 4080606** with it pre-filled. A "Send by
email" button is also offered. The cart is stored in the visitor's browser.

## Editing content

Everything is in **`js/data.js`**:

- `SITE`: phone, WhatsApp, **email (placeholder, replace with the real one)**, address, hours, homepage stats
- `CATEGORIES`, `PRODUCTS`: catalogue, prices (indicative Rs. per unit), MOQ, sizes, features
- `PROJECTS`: portfolio items
- `TESTIMONIALS`: **placeholders, replace with real customer feedback before going live**
- `FAQS`, `INDUSTRIES`
- `PHOTOS`: large background photos (Unsplash). Each has a local fallback, so the site still looks complete if they don't load. Replace them with real factory photos, e.g. `"img/factory-1.jpg"`.

Product images in `img/products/` are vector illustrations generated by
`tools/make_images.py`. To use a real photo, put it in `img/products/` (e.g. `rice-bag.jpg`)
and set that product's `img: "rice-bag.jpg"` in `js/data.js`.
