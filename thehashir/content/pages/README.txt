Put legal page content here as HTML files named:

  privacy-policy.html
  cookie-policy.html
  disclaimer.html
  copyright-notice.html
  terms.html

Use simple HTML only (<h2>, <h3>, <p>, <ul>, <li>, <a>). No <html>/<head>/<body> tags.
Each file that exists becomes a page (e.g. /privacy-policy) and is linked in the footer automatically.
This folder is blocked from direct web access by .htaccess.
