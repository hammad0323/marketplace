# Admin Guide — where everything lives

| You want to… | Go to |
|---|---|
| See sales, order pipeline, best sellers, low stock | **Dashboard** |
| Process orders, print invoices or packing slips, add tracking, notes, refunds, export CSV | **Orders** → open an order |
| Mark COD cash collected | Order page → *Payment* → **Mark COD collected** |
| Find a customer, disable an account, send a password reset | **Customers** |
| Discount codes | **Coupons** |
| Gateway events, reconciliation | **Payment log** |
| Add or edit products, variants, stock, images, video, craft details, made-to-order options, SEO, related products | **Products** |
| Duplicate a product | Products → copy icon (creates a draft) |
| Category tree, images, banners, SEO, homepage selection | **Categories** (drag to reorder; unlimited nesting) |
| "Shop by Craft" collections and the Handcrafted Collection | **Collections** |
| Stock adjustments, low stock, movement history | **Inventory** |
| New sizes (e.g. 62"), colours (with swatch), filter attributes, size guides | **Sizes, colours & attributes** |
| Approve reviews, feature them as testimonials | **Reviews & testimonials** |
| Homepage section order, visibility, text, images, buttons, colours, spacing, width, animation, plus hand-picked products, categories and collections | **Homepage builder** (Save draft → Preview → Publish) |
| Hero slides: desktop/mobile image, text, buttons, alignment, position, colours, overlay, heights, focus, parallax | **Hero slides** |
| Hero autoplay, duration, transition | Homepage builder → Hero |
| Header menu, dropdowns, footer links, label colours | **Navigation** |
| About, Size Guide, Care Guide, policies, FAQs | **Content pages** |
| Colours, fonts, buttons, cards, widths, spacing, header and mobile nav, footer layout, animations | **Theme** (draft → preview → publish) |
| Logo, favicon, contact details, currency, announcement bar, social links, checkout texts, email/SMTP | **Store settings** |
| Delivery zones, rates, free delivery, minimum order, express, COD by area | **Shipping & delivery** |
| COD, JazzCash, Easypaisa, card | **Payment methods** |
| Default SEO, Search Console, analytics, robots.txt, ads.txt, redirects, sitemap | **SEO & redirects** |
| Newsletter subscribers (with consent records) and contact messages | **Newsletter & messages** |
| Staff accounts, role permission matrix | **Admin users & roles** |
| Who changed what | **Audit log** |

**Preview.** "Save draft & preview" opens the storefront in preview mode, where you, signed in as an admin, see the draft theme and homepage. Visitors keep seeing the published version. Use *Exit preview* in the yellow bar to leave.
