# Signal Signage — Flutter apps

One codebase, two apps:

- `lib/main.dart`: management app (users and super admin), Android/iOS/web
- `lib/main_player.dart`: Android TV / box / tablet signage player

See `../README.md` and `../docs/DEPLOYMENT.md` for build and run instructions.

Run the checks:

```bash
flutter analyze
```

```bash
flutter test
```
